TechFlow Dashboard
Projeto desenvolvido para o Checkpoint 5 — FrontEnd Design.

-----------------------------Integrantes ------------------------------------------------
Giulia Stella  - rm568888

---------------------------Tecnologias utilizadas-----------------------------------------

HTML semântico
Tailwind CSS
Vite
JavaScript puro

------------------------Principais recursos implementados-------------------------------

Dashboard responsivo mobile-first com Navbar, Sidebar, indicadores, projetos e feed de atividades.

CSS Grid com grid-cols, col-span e cards de tamanhos diferentes.

Menu da Sidebar para mobile e dropdown do usuário.

Busca instantânea de projetos com case sensitive para conseguir mesmo com letras minusculas ou maiusculas.

Modal de novo projeto com validação visual de campos obrigatórios e estado de sucesso.

Estados hover, focus, active, disabled, group-hover e transições com Tailwind.

Tema Light / Dark / System com dark: e persistência no localStorage.

Breakpoints sm, md, lg, xl e 2xl.


------------------------------Como executar-------------------------------------------

Bash:

npm install
npm run dev

Depois, abra a URL exibida pelo Vite.
